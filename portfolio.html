01

Perch / Flock

An edge-vision device, and the fleet backend that keeps it updated.

Role
ML pipeline and fleet backend
When
Oct 2026 to present
Built with
Raspberry Pi 5, Hailo-8L, YOLO, Python, SQLite, Prometheus, Grafana, OTA updates, QAT

  1. On the device

    Perch

    A Raspberry Pi 5 with a Hailo-8L. I’m building its ML pipeline: a YOLO nano detector compiled to Hailo HEF, a Python inference runtime, and a SQLite queue so detections survive network drops.

  2. Across the fleet

    Flock

    The backend I’m building alongside it: a device registry, heartbeat telemetry, and signed over-the-air model updates with canary rollout and automatic rollback.

  3. On the dashboard

    Prometheus and Grafana

    Dashboards for the fleet, fed by the telemetry Flock collects.

  4. And back again

    Retraining loop

    A closed loop I’m designing: on-device hard-example mining, fine-tuning with quantization-aware training, held-out evaluation, then fleet-wide deployment.

Still in progress. The repository isn’t public.
